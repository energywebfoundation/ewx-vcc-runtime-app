#### Overview
Energy Web VCC Runtime is the lightweight desktop runtime for Energy Web’s Verified Compute Cloud (VCC). Designed to run with minimal UI (menu bar/taskbar), it lets your computer execute verifiable workloads in the background for real‑world energy and sustainability applications.

##### VCC, in plain English
Verified Compute Cloud (VCC) is a decentralized off‑chain business logic computation service (a “layer 2”) that complements and interacts with Energy Web X blockchain for on‑chain finalization. VCC is operated by distributed operators who execute deterministic workflows and the network can verify and finalize results on-chain.

##### What this app does
<ul>
  <li>Connects to external self‑custodial wallets for authentication (no username/password signup).</li>
  <li>Runs verification logic workloads. A VCC Runtime is a processing unit in a network of nodes that can execute enterprise calculations and submit votes to derive consensus‑based, transparent results.</li>
  <li>Downloads approved “solution” workflows and executes them locally, then submits verifiable outputs back to the network.</li>
</ul>

Typical workload examples (depends on the verification solution group)
<ul>
  <li>Computing an energy load forecast</li>
  <li>Validating batches of renewable energy certificates</li>
  <li>Other sustainability verification workflows that require auditability without sharing raw, commercially sensitive data</li>
</ul>

##### If you used Energy Web Marketplace before
The Marketplace user interface is moving to the web. This Runtime focuses only on running the compute component on your device.

##### Not a crypto exchange
Energy Web VCC Runtime does not provide exchange services, trading, or custody of crypto‑assets. Your private keys stay in your wallet. Any protocol rewards/fees (if applicable) are defined by on‑chain rules, may vary, and are not guaranteed.
